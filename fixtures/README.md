# Optional real photos

The demo does not need anything here: it uses the two **synthetic demo images** (computer-generated, not real photos) in `backend/data/fixtures/`.

If you have real photos of the physical build, add them here and the app will list them as extra samples:

| File | What it should show |
| --- | --- |
| `correct.jpg` | The build wired exactly as the template `uno_d9_led_220r` describes. |
| `wrong_wire.jpg` | The same build with one deliberate wiring mistake. |
| `blurry.jpg` | A deliberately blurry photo, to check Wirewise asks for review instead of passing it. |
